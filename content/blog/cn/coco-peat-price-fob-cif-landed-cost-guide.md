"椰糠多少钱？"这是我们收到的几乎每一封询盘的第一个问题，也是任何一家诚实的出口商都无法用一个数字回答的问题。椰糠价格随等级、配比、规格、水分、包装、集装箱类型、航线，以及椰糠原料收获的季节而变动。两份纸面上相差 20% 的报价，算完账后往往完全相同——有时便宜的那份反而是更贵的基质。本指南将说明一份椰糠报价单里究竟包含什么、如何把 FOB 换算成到岸成本，以及能公平比较任意两家供应商的那个唯一指标。

## 为什么"每吨多少钱"几乎说明不了任何问题

椰糠不是那种像一吨尿素一样的标准大宗商品。一吨未洗椰糠和一吨完全钙缓冲、过筛、低 EC 的椰糠，是制造成本不同的两种产品，在温室里也不能互换使用。

更麻烦的是，每吨单价悄悄掩盖了您真正要买的东西——**可用根区基质的体积**。一块水分 18%、含砂 6% 的椰砖，重量与一块充分干燥、过筛的椰砖相同，但产出的基质明显更少。您是按基质的价格买了水和砂。

所以，请把网上查到的任何"椰糠每吨价格"当作一个起始坐标，而不是报价，并尽快转向**贵司厂区到岸口径的每可用升成本**。

## 真正推动价格的八个因素

| 因素 | 影响 | 为什么会改变数字 |
| --- | --- | --- |
| **等级**（未洗 → 水洗 → 缓冲） | 单一因素中影响最大 | 水洗消耗淡水、场地和晾晒时间。缓冲则增加硝酸钙投入和第二道加工工序。 |
| **配比**（椰糠 / 椰块 / 混配） | 中等 | 椰壳块需要切割和分级。60:40 配比的制造成本高于纯椰糠。 |
| **规格** | 大 | 压缩 5 kg 椰砖是最便宜的形态。种植袋和栽培垫要加上薄膜、成型、缓冲和人工。 |
| **水分上限** | 中等 | 10–15% 的上限意味着实打实的晾晒时间。有些供应商"做到"低价，靠的就是发湿一点的货。 |
| **过筛与杂质上限** | 中等 | 把砂与杂质压到 3% 以下需要一道有收率损失的筛分工序。 |
| **包装与托盘化** | 约占 FOB 的 3 – 8% | 托盘、收缩膜、印刷塑料袋、出口纸箱都要成本，托盘还会占用载重。 |
| **检测与认证** | 金额不大但真实存在 | 批次第三方检测报告、植物检疫证书、熏蒸证书都是独立费用项。 |
| **数量与季节** | 中等 | 整柜价格明显优于拼箱。雨季晾晒场周转变慢，供应趋紧。 |

其中两项需要特别提醒。如果某份报价远低于其他投标，最可能的原因是**水分与杂质**（您买的是水和砂），或者是**按水洗规格报了未洗等级**。这两点在形式发票上都看不出来，在检测报告上却一目了然。

## 读懂报价：FOB、CFR、CIF 与 DAP

供应商之间一半的"价差"，实际上是贸易术语的差异。在比较任何数字之前，先确认每份报价用的是哪个术语。

| 贸易术语 | 卖方承担至 | 您额外承担 |
| --- | --- | --- |
| **EXW** | 仅工厂交货的货物本身 | 印度国内运输、出口报关、海运费、保险及此后全部费用 |
| **FOB**（装运港） | 货物、出口报关、内陆运输、装船 | 海运费、保险、目的港费用、关税、送货 |
| **CFR / CNF** | 以上 + 至目的港海运费 | 保险、目的港费用、关税、送货 |
| **CIF** | 以上 + 海运保险 | 目的港费用、关税、进口清关、送货 |
| **DAP** | 送达指定地址 | 进口关税与税费（DDP 除外） |

同样的货物，CIF 报价看起来永远比 FOB 贵。这不是价差，而是**范围差异**。印度出口的整柜椰糠贸易大多以 **FOB 印度港**或 **CIF 目的港**成交，而多数有经验的进口商偏好 FOB——他们自己掌控订舱，且往往用自有合约拿到比出口商更好的运价。

## 从 FOB 到到岸：完整成本结构

以下是一整柜 40ft 高柜、散装地板装载的 5 kg 水洗低 EC 椰砖的完整成本结构。第一行填入您自己报价单上的数字，其余各行则是进口商最常漏算的部分。

| 成本项 | 说明 |
| --- | --- |
| **1. FOB 货值** | 报价每吨单价 × 整柜吨位（散装地板装柜约 24–26 公吨） |
| **2. 海运费 + 燃油等附加费** | 完全取决于航线与季节。建模之前先拿到您那对港口的实时运价。 |
| **3. 海运保险** | 通常为 CIF 货值的约 0.3 – 0.5% |
| **4. 目的港 THC 与港杂费** | 按柜固定，而非按吨——因此对满柜极为有利 |
| **5. 进口关税** | 按 HS 53050040 归类。多个市场为零关税，但务必核实贵国税率，切勿想当然 |
| **6. 报关行与清关费** | 按报关单笔数固定 |
| **7. 至厂区内陆运输** | 按柜计 |
| **8. 卸柜人工与滞港风险** | 散装地板装柜比托盘化拆柜慢得多——见[装柜指南](https://www.ppmcocopeat.com/cn/blog/5kg-coco-peat-blocks-40ft-container-loading-guide) |
| **9. 您自身的加工成本** | 用水、人工，以及若采购未缓冲料还需缓冲药剂 |

第 4、6、7 项是**按柜固定**的。这正是半空柜采购椰糠代价高昂的算术原因，也是把两笔小订单合并成一整柜通常比两票拼箱更划算的原因——即便把持有库存的成本算进去也是如此。

## 比较两份报价的唯一指标：每可用升成本

把每一份报价都换算成这个指标，胜出的往往不是标价最低的那家。

**到岸每升成本 =（整柜到岸总成本）÷（椰砖数量 × 每块可用基质升数）**

分母的后半部分正是各家报价分道扬镳之处。一块能复水成 80 升、杂质 3% 的洁净过筛基质的椰砖，和一块只能复水成 70 升、还在筛子里留下砂粒的椰砖，不是同一种资产。以 4,800 块的整柜计算，这就是 48,000 升的差距——一个您在发票上永远看不到的规格差异，却能让真实每升成本波动超过 10%。

要做对这个比较：

1. **统一贸易术语。** 用同一个运价，把每份报价都换算成您码头到岸口径。
2. **统一体积。** 向每家供应商索取每块保证复水升数，而不只是椰砖重量。
3. **对不合规风险打折。** 不肯把 EC 上限、水分上限、杂质上限写进合同的供应商，其实际价格高于报价——因为风险由您承担。
4. **加上您自己的加工成本。** 为需要缓冲的用途采购未缓冲料并不便宜，只是把缓冲成本转移到了您的工资单上。
5. **然后，才开始比较。**

> **一个快速检验：** 如果两家供应商的到岸每升成本相差在 5% 以内，价格就不再是决定变量。请改以稳定性、单证质量和响应速度来选择——这些才决定下个生产季您的水肥方案是否稳定。

## 为什么最便宜的报价常常反而亏钱

失败的形态总是相同：买家提出的是温室作物，接受的却是按未洗或轻度水洗椰糠定价的投标，然后在作季第四周发现盐分问题——钙镁被拮抗锁定，作物停止生长。基质上省下的那点钱，在损失的一个作季面前只是舍入误差。如果您的作物对盐敏感，请在签字前先读[低 EC 与高 EC 采购指南](https://www.ppmcocopeat.com/cn/blog/low-ec-vs-high-ec-coco-peat-procurement-guide)。

## 季节性、交期与下单时机

椰糠是在露天场地晾晒的。仅这一点就决定了整个日历：

- **雨季晾晒变慢**，真正低水分、低 EC 原料的供应趋紧，价格走强。
- **旺季前需求集中**，北半球的采购高峰恰好压在同一个生产窗口上。
- **交期 = 生产 + 单证 + 航程**：通常在装船前有数周制造期，再加上运输时间。请按定植日历下单，而不是按库存告罄日下单。

提供年度滚动预测、按季度分批提货的买家，始终能拿到比一年只出现一次、开口就要下周走货的买家更好的价格和舱位。

## 如何索取一份真正可比的报价

给每家供应商发同一份询价书。只需五分钟，却是采购周期中回报最高的一件事：

- 原料与配比、等级、**注明浸提方法的** EC 上限、pH 区间、水分上限、杂质上限
- 规格与尺寸，以及每单位保证复水升数
- 柜数、集装箱类型、托盘化或散装地板装柜
- 明确写出**贸易术语与指定港口**
- 您可接受的付款条件，以及是否包含批次检测报告和付费样品
- 您的目标交货窗口

顺带一提，付款条件本身也是价格的一部分。预付款对供应商而言的资金成本低于即期信用证，而这个差额是可以谈的；预付一部分、余款凭提单副本支付，是重复交易中常见的折中方案。
